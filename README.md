# PDF 가격 수정기

PDF 위에 **지울 영역**과 **숫자를 바꿀 영역**을 마우스로 지정하고, 그 설정을 **템플릿**으로 저장해
같은 양식의 PDF에 반복 적용하는 오프라인 데스크톱 프로그램입니다.

- 인터넷 연결 없이 동작 (`dist\PdfPriceEditor.exe` 하나만 복사하면 됨)
- PowerPoint·Acrobat 설치 불필요
- 원본 PDF는 절대 덮어쓰지 않음

## 사용 순서

### 1) 템플릿 만들기 (양식당 한 번)
1. **PDF 열기** (또는 창에 끌어다 놓기)
2. **＋ 숫자 영역**(N)을 누르고 단가·수량·금액 칸을 드래그로 지정
   - 원본 표기(₩, 원, 쉼표, 소수 자리, 정렬)는 자동으로 감지됩니다.
   - 오른쪽 **이름**을 `단가1`, `수량1`, `금액1` 처럼 바꿔 두세요. 수식에서 이 이름을 씁니다.
3. 계산되는 칸에는 **수식**을 넣습니다.

   | 칸 | 수식 예 |
   |---|---|
   | 금액1 | `단가1*수량1` |
   | 공급가액 | `SUM(금액*)` ← '금액'으로 시작하는 모든 영역의 합 |
   | 부가세 | `ROUND(공급가액*0.1)` |
   | 합계 | `공급가액+부가세` |

   사용 가능한 함수: `SUM`, `ROUND`, `ROUNDUP`, `ROUNDDOWN`, `MIN`, `MAX`, `ABS`
   (`ROUND(x, -3)`은 천 원 단위 반올림)
4. **＋ 지울 영역**(E)으로 담당자 연락처 등 지울 부분을 지정
5. **템플릿 저장** → `.json` 파일

### 영역 안 텍스트 읽기 — 지울 글자만 골라 지우기
영역을 선택하면 오른쪽 **영역 안 글자** 목록에 그 범위의 텍스트가 단어 단위로 표시됩니다
(**텍스트 복사** 버튼으로 클립보드에 복사도 가능).

- **지우기 영역**: 기본 방식은 *글자 골라 지우기*입니다. 체크한 단어만 지우고 나머지는 남깁니다.
  PDF 위의 단어를 눌러도 지움(빨간 취소선) ↔ 남김(초록)이 바뀝니다.
  - 예) `담당자: 홍길동 010-1234-5678` → `담당자:`만 남기고 이름·연락처만 지움
  - 규칙은 **글자 기준**으로 템플릿에 저장되어 다른 PDF에도 적용됩니다.
    목록에 없던 글자(다른 담당자 이름 등)는 *다른 문서에서* 설정(기본: 지움)을 따릅니다.
  - 남기기로 한 글자가 새 PDF에 없으면 "양식이 다를 수 있다"고 경고합니다.
  - 도장 이미지처럼 글자가 아닌 것까지 지우려면 *영역 전체 덮기*를 고르세요.
- **숫자 영역**: 숫자가 든 단어만 교체하고 같은 영역의 라벨·단위(`합계`, `EA` 등)는 그대로 둡니다.
  그래서 영역을 칸에 딱 맞게 그리지 않아도 됩니다.

영역은 **선택/이동**(V) 모드에서 끌어서 옮기고, 오른쪽 아래 모서리를 끌어 크기를 바꿉니다.
Delete 키로 삭제합니다.

### 2) 문서마다 적용
1. PDF 열기 → **템플릿 열기** (둘 다 창에 끌어다 놓아도 됨)
2. 영역 목록의 노란 **새 값** 칸에 바꿀 단가·수량을 입력
   - 비워 둔 칸은 **원본 값을 그대로 유지**하고, 수식 계산에만 원본 값을 씁니다.
   - 결과가 원본과 같은 칸은 건드리지 않습니다.
3. **결과 미리보기**(F5)로 확인
4. **결과 PDF 저장**(Ctrl+S) → `원본명_수정본.pdf` + `원본명_수정본_변경내역.csv`

## 엑셀 품번 목록과 대조하기 (여러 품목을 한 번에)
품번·가격을 적은 엑셀을 불러와 PDF의 품목 표와 줄 단위로 대조합니다.

1. **엑셀 품번 불러오기**(Ctrl+E) 또는 엑셀 파일을 창에 끌어다 놓기 (.xlsx, .csv)
   — 품번 열·가격 열을 자동으로 찾고, 맞는지 미리보기에서 확인·변경할 수 있습니다.
2. **＋ 품번 대조 영역**(L)으로 PDF의 품목 표 전체를 드래그
3. 결과 확인 → **결과 PDF 저장**

| PDF의 줄 | 처리 |
|---|---|
| 엑셀에 있는 품번 | **유지**. 같은 줄의 가격을 엑셀 가격과 비교 |
| └ 가격이 다름 | 엑셀 가격으로 바꿈 (원본과 같은 글꼴·크기·색) — 또는 *표시만* 선택 가능 |
| 품번 모양인데 엑셀에 없음 | **줄 전체 삭제** — 또는 *표시만* 선택 가능 |
| 품번이 없는 줄 (머리글, 비고, 합계 등) | 유지 |
| 엑셀 품번과 비슷함 (OCR이 0/O, 1/I, 8/B 등을 헷갈렸거나 한 글자 다름) | **지우지 않고 유지, ⚠ 확인 필요로 표시** |

- 품번 비교는 대소문자·공백·하이픈을 무시합니다 (`ab-12` = `AB12`).
- 가격 열은 엑셀 가격과 정확히 일치한 줄들로부터 위치를 자동으로 알아냅니다.
- **대조 결과**(Ctrl+R): 엑셀 품번 하나하나가 PDF에 있었는지, 가격이 맞았는지, PDF에만 있던 품번은 무엇인지
  한 표로 보여 줍니다 (확인 필요한 것만 보기, CSV 저장).
- 저장하면 `원본명_수정본_엑셀대조.csv`가 함께 만들어집니다.
- 엑셀 목록은 작업마다 바뀌므로 템플릿에는 저장되지 않고, *영역 위치와 처리 방식*만 템플릿에 저장됩니다.
- 예전 형식(.xls)은 엑셀에서 .xlsx로 저장한 뒤 불러오세요. 한 품목이 두 줄에 걸친 표는 아직 줄 단위로만 처리합니다.

## 이미지 PDF (스캔본, "PDF로 인쇄"한 문서)
정부24 발급 문서처럼 PDF 프린터로 저장한 문서는 글자 정보 없이 그림만 들어 있습니다.
이런 PDF를 열면 **자동으로 OCR(글자 인식)**을 실행합니다 (한 쪽에 10초 안팎, 인터넷 불필요).

- OCR로 읽은 단어도 텍스트 PDF와 똑같이 *글자 골라 지우기*, *숫자 교체*를 쓸 수 있습니다.
- 지울 때는 덮기만 하는 것이 아니라 **이미지 픽셀 자체를 지우고** 원래 배경색으로 채웁니다
  (덮개를 걷어내도 원래 글자가 남지 않음).
- 새 숫자는 원래 글자의 크기·색·위치를 이미지에서 재서 그 자리에 씁니다.
- 인식이 불확실한 단어는 *영역 안 글자* 목록에 ⚠로 표시됩니다. 꼭 원본과 비교해 보세요.
- 저장할 때 결과 PDF를 **다시 OCR해서** 의도대로 바뀌었는지 검증합니다.
- 일부만 그림이거나 글자가 깨져 읽히는 PDF는 도구 모음의 **글자 인식(OCR)** 으로 직접 실행할 수 있습니다.

OCR 엔진: RapidOCR + PaddleOCR 한국어 모델(onnxruntime). 모델은 exe 안에 들어 있습니다.

## 새 글자를 원본과 같은 글꼴·크기·색으로
숫자 영역을 선택하면 설정 패널의 **원본 서식**에 감지한 글꼴·크기·색과 감지 방법이 표시됩니다.

- **텍스트 PDF**: PDF 안에 들어 있는 원본 글꼴을 그대로 다시 씁니다. 원본이 일부 글자만 담은
  부분 글꼴이라 새 숫자가 없으면, 같은 이름의 Windows 글꼴(굵게 여부 포함)을 씁니다. 크기·색은 PDF 값 그대로.
- **이미지 PDF**: 원본 글자 그림을 설치된 글꼴(바탕·굴림·돋움·맑은 고딕·나눔·HY·Arial 등)로 직접 그려 비교해
  가장 닮은 글꼴과 크기를 고르고, 글자 가장자리 번짐을 감안해 실제 글자색을 계산합니다.
  새 글자는 **원본 이미지와 같은 해상도·픽셀 격자의 그림**으로 넣어 번짐 정도까지 맞춥니다.
  같은 줄의 다른 글자(특히 한글)도 근거로 쓰기 때문에, 숫자만 있는 칸도 글꼴을 구분할 수 있습니다.
- 감지가 틀리면 **글꼴 / 글자색 / 크기**를 직접 지정할 수 있고, 지정값은 템플릿에 저장됩니다.

검증(테스트): 바탕·굴림·돋움·맑은 고딕·Arial Bold, 9~12pt, 여러 색으로 만든 문서에서
텍스트 PDF는 원본 글꼴·크기·색이 정확히 같고, 이미지 PDF(150·200dpi)는 글꼴 10/10 일치, 크기 ±0.2pt,
색 오차 RGB 각 7~9% 이내입니다.

## 사람이 하던 검증을 줄여 주는 장치
- **저장 직후 자동 검증**: 결과 PDF를 다시 읽어, 영역마다 *남아야 할 글자는 남고 지울 글자는 사라졌는지*,
  새 숫자가 정확히 들어갔는지 단어 단위로 확인
- **변경 내역 CSV**: 영역별 원본 → 변경 후, 지운 글자, 검증 결과 (엑셀에서 바로 열림)
- **템플릿 적용 전 점검**: 페이지 수·크기가 다르거나, 영역에 있어야 할 글자가 없으면 경고
- 오류(숫자가 아닌 입력, 없는 이름 참조, 순환 참조)가 있으면 저장을 막음

## 알아둘 제한
- **OCR은 완벽하지 않습니다.** 특히 짧은 글자, 흐린 스캔, 손글씨는 틀릴 수 있으니 ⚠ 표시된 단어와 미리보기를 확인하세요.
- 원본 글꼴이 이 PC에 설치되어 있지 않고 PDF 안의 글꼴에도 새 숫자가 없으면, 비슷한 글꼴 대신 **맑은 고딕**으로 씁니다
  (원본 서식에 "기본 글꼴"로 표시됨). 이때는 글꼴을 직접 지정하세요.
- 템플릿은 **좌표 기준**입니다. 같은 양식이라도 품목 행 수가 달라 표가 밀리면 영역을 다시 맞춰야 합니다.
- 회전된 페이지는 위치가 어긋날 수 있어 경고를 띄웁니다.
- PyMuPDF는 AGPL 라이선스입니다. 사내에서 쓰는 것은 문제없지만, 외부에 배포하거나 판매하려면 라이선스를 검토하세요.

## 개발

```
pdf_price_editor/
├── core/            # GUI와 무관한 로직 (테스트 대상)
│   ├── models.py    # Region, Template (JSON 저장/불러오기)
│   ├── numbers.py   # 숫자 파싱·표기
│   ├── formula.py   # 안전한 수식 계산기 (eval 미사용)
│   ├── engine.py    # 읽기 → 계산 → 적용 → 검증
│   ├── ocr.py       # 이미지 PDF용 오프라인 OCR
│   ├── fonts.py     # 원본 글꼴·크기·색 찾기, 새 글자 그리기
│   ├── bulk.py      # 엑셀 품번 목록 읽기·품번 비교
│   └── words.py     # 텍스트 레이어/OCR 공통 단어 자료형
├── app/             # PySide6 화면
├── tests/           # pytest + 샘플 견적서 생성기
├── tools/           # PDF 진단, OCR 모델 준비
├── examples/        # 샘플 PDF와 템플릿
├── main.py
└── build.bat        # exe 빌드
```

- 테스트: `.venv\Scripts\python -m pytest -q` (OCR 테스트 포함, 40초 정도)
- OCR 모델 준비: `.venv\Scripts\python toolsetch_models.py` → `models/` (약 24MB, git에는 올리지 않음)
- PDF 진단: `.venv\Scripts\python tools\diagnose_pdf.py 파일.pdf` — 글자를 왜 못 읽는지(스캔본/글꼴 깨짐/양식 필드) 확인
- exe 빌드: `build.bat` 실행 → `dist\PdfPriceEditor.exe` (약 166MB)
  (처음 한 번만 라이브러리·모델 설치에 인터넷이 필요합니다)
- exe 안의 OCR 점검: `PdfPriceEditor.exe --ocr-selftest 입력.pdf 결과.txt`
